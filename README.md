# ISKRA: 360 Światów

Neonowa platformówka 2D w HTML, CSS i JavaScript.

## Uruchomienie

Otwórz `index.html` w nowoczesnej przeglądarce. Nie wymaga instalacji zależności ani serwera.

## Sterowanie

- A / D lub strzałki: ruch
- W, strzałka w górę lub spacja: skok
- Na urządzeniach dotykowych użyj przycisków na ekranie

## Plan gry

- 360 poziomów: 12 biomów po 30 etapów
- Proceduralnie generowane przeszkody i nagrody
- Kolce, ruchome platformy, przeciwnicy, klucze, checkpointy i bossowie
- Lokalny zapis postępu w przeglądarce

## Stack

Vanilla JavaScript, HTML Canvas, CSS. Brak zewnętrznych zależności.
